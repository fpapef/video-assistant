Video Assistant

Le bouton « ouvrir dans le lecteur » de Samsung Internet, pour tous les navigateurs.

1. Favori (marche presque partout, y compris sur Quest)

▶ Lecteur vidéo

  1. PC : glisse le bouton bleu dans ta barre de favoris.
  2. Quest / mobile / TV : copie le code ci-dessous, crée un favori de n'importe quelle page, puis remplace son adresse (URL) par ce code.
  3. Sur une page avec une vidéo, ouvre ce favori : la vidéo passe dans le lecteur.

2. Bouton flottant automatique (PC, Firefox Android, Kiwi…)

Installe Violentmonkey ou Tampermonkey, puis ouvre le fichier video-assistant.user.js : un bouton bleu apparaît tout seul en bas à droite dès qu'une vidéo joue.
